# Example resume

Replace this file with your own. The scorer reads it verbatim and quotes from it
in the `strengths` field of every assessment, so plain Markdown works best —
no tables, no columns, no images.

What matters for scoring:

- **Titles and dates**, so seniority can be inferred.
- **Scope**, in numbers: team size, budget, systems owned, coverage.
- **Outcomes**, in numbers: what changed and by how much.
- **The vocabulary of your field**, because `profile.domains` in `config.yaml`
  is matched against posting text and weighed against what this file evidences.
